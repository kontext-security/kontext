# Catalog authority readers

Verified against the public sources below on 2026-09-19 and, for Factory's top-level autonomy key, a user-confirmed settings file from September 2026. These are user configuration facts, not effective session policy. Runtime flags, project overrides, enterprise caps, and host approval state can change execution behavior. No settings file is executed, and no environment variable or path inside a settings file is expanded or followed.

## Permission interpretation

`auto` means an explicit persisted no-prompt setting: OpenClaw `full` or legacy `security=full,ask=off`; Qwen `yolo` or `auto-edit`; Goose `auto`; Factory `high` or `auto-high` on any of its three supported keys; Kimi `default_permission_mode=auto/yolo` or legacy `default_yolo=true`; Auggie a wildcard allow before any deny; Crush `bash` in `permissions.allowed_tools`; Kilo unconditional `allow`; Junie `brave=true`; Grok `always-approve`; Hermes `off`. Other present values report `default`; absence remains null. Kimi `yolo` retains sensitive-file prompts but is the vendor's run-without-asking mode. Other classifier modes that can still ask and Factory's low/medium levels report `default`. Auggie per-tool allows and denies before a wildcard allow report `default`; pattern text is ignored. Factory command allowlists and denylists are never read.

## Deliberate coverage limits

- Pi has no native MCP configuration or persisted permission switch. Its fixture proves package metadata, with empty MCPs and null mode. No synthetic MCP file or permission setting is invented.
- Devin has no verified persisted global permission-mode key in the cited sources, so its mode stays null. Crush's runtime-only `--yolo` is not read; its persisted `allowed_tools` is checked for `bash`. Auggie's ordered wildcard rule determines its mode; per-tool rules do not establish a global no-prompt setting.
- OpenClaw accepts full JSON5 upstream. This reader uses the required existing JSONC decoder: JSON, comments, and trailing commas work; unquoted keys and single-quoted strings produce a coverage parse error. No new JSON5 dependency is introduced.
- OpenClaw plugin enablement reports user-level configuration for external plugins. Runtime channel activation, exclusive slots, bundled plugins, and project overrides are outside this scan.
- Pi package scanning covers npm manifests with an explicit `pi` declaration. Git and external local package roots are not followed. Qwen linked/external extensions and workspace activation overrides are not followed.
- Factory, Auggie, Junie, and Grok document plugin/extension systems, but the reviewed public sources do not establish a complete local installed-manifest path plus activation mapping. Those plugin readers are skipped rather than assuming Claude's cache layout. Kilo loads executable plugins without a required manifest, which this scanner does not execute.
- Grok's legacy `approval_mode`/`yolo` aliases are not read because the cited public guide does not disambiguate their persisted table placement.

The YAML decoder was already in the module graph through `github.com/stretchr/testify@v1.11.1 -> gopkg.in/yaml.v3@v3.0.1`; this change promotes that exact version to a direct dependency.

## Verification

Each new catalog ID has a fixture home and golden report. `home_generic` contains the explicit off values where a persisted toggle exists. Tests also cover all 25 catalog IDs, unknown future IDs, malformed files, cache invalidation, symlink rejection, config precedence, scoped npm packages, and Cline/Kimi/Crush overrides. Kimi's current and legacy environment variables, config keys, and home directories are covered. Cline, OpenCode, Kimi, and Crush overrides cannot authorize files outside home. No report fields are added. Staging drawer verification remains Michel's step after deployment; this PR does not deploy or touch the running daemon.
